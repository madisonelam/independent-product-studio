# independent-product-studio
Original pattern design and small-batch production studio — end-to-end process from concept sketch to finished product, covering iterative design, QC/tolerance validation, and inventory-scaled production. 30+ original designs, 100+ units shipped, 95% customer satisfaction.


Overview

Independent Product Studio began as a hands-on design practice and grew into a small production operation with a self-built e-commerce storefront, a repeatable QC process, and a growing catalog of 30+ original designs. The work spans the full product lifecycle: drafting original patterns, iterating through prototype revisions, validating finished pieces against tolerance-based quality criteria, and managing inventory and fulfillment for direct-to-customer sales.

Designs include original character-inspired pieces created as fan work; this repo focuses on the underlying design and production process rather than specific licensed characters.


What's Documented

Original pattern drafting — designed 30+ original patterns from concept sketch through iterative revision, refining fit, proportion, and construction method across multiple draft cycles

Stage-gate QC pipeline — built a structured, tolerance-based inspection process applied at defined checkpoints (materials, mid-construction, finishing) to catch defects before completion, reducing product defect rate by 20% across the catalog

Production scaling — implemented end-to-end inventory control and documented build processes to scale from one-off pieces to 100+ produced units while maintaining consistency

Process documentation — created reusable, written construction and QC documentation so designs could be reproduced consistently across batches

Direct-to-customer e-commerce — designed, built, and run an independent website for pattern and product sales, plus social media for design showcase and customer engagement
